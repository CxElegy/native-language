# Native Language

收集我觉得**地道、好看、有味道**的 native 语言用法。

不是词典，也不是语法书——只收我自己读到/听到时会心一笑、想偷来用的说法。

## 结构

```
inbox.md              # 随手丢：看到就先贴进来，不用整理
collection/           # 整理后的条目，按场景分类
  daily.md            # 日常口语
  writing.md          # 书面 / 写作
  work.md             # 职场 / 沟通
  emotion.md          # 情绪、态度、语气
  idioms.md           # 习语、俚语、固定搭配
  praise.md           # 夸奖与评价
TEMPLATE.md           # 条目格式
```

## 怎么用

1. 看到喜欢的句子 → 先丢进 `inbox.md`（原句 + 出处就够了）。
2. 有空时整理成条目，挪到 `collection/` 对应文件。
3. 也可以直接把句子发给 Claude，让它按 `TEMPLATE.md` 整理并归类。

## 收录标准（我的审美）

- 母语者真的会这么说，而不是教科书式的“正确”
- 简洁、有画面感，或者语气拿捏得很准
- 能替换掉我原本会说的那种笨拙/中式表达
